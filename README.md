# Shihong Duan / 段世红

Personal academic homepage: <https://duanabao.github.io/>

Associate Professor, School of Computer and Communication Engineering, University of Science and Technology Beijing. Research on multi-agent reinforcement learning, swarm-robot cooperative localization, near-ground UWB communication, and wireless sensing.

## Edit the site

This site uses the [academicpages](https://github.com/academicpages/academicpages.github.io) Jekyll template and GitHub Pages.

| What | Where |
| --- | --- |
| Site-wide profile and links | `_config.yml` |
| Homepage | `_pages/about.md` |
| Papers | `_publications/` |
| Talks | `_talks/` |
| Teaching | `_teaching/` |
| CV | `_pages/cv.md` |
| Menu | `_data/navigation.yml` |

Push to `master` to update the live site.

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
